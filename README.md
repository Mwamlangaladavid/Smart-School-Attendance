# Smart-School-Attendance
This project aims to develop an innovative biometric based Student Security and attendance monitoring system that ensures the safety and accountability of students. Traditional attendance tracking methods, such as manual roll calls or RFID systems, have significant shortcomings, including inaccuracies and delays in notifying parents. The proposed solution leverages biometric technologies, such as fingerprint and facial recognition, to automate attendance tracking, prevent proxy attendance, and send real time updates to parents about their child’s arrival and departure. This system will also facilitate leave applications and generate attendance trend reports. The expected outcomes are enhanced student safety, improved administrative efficiency, and better communication between parents and school authorities.
