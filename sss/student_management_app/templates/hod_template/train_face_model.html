Instructions
How to prepare for face recognition:
  1. Ensure all students have clear profile pictures or have been enrolled using the camera
  2. Click "Generate Face Encodings" to process all student images
  3. Click "Start Training" to build the face recognition model
  4. Once training is complete, staff can use face recognition for attendance
Best practices for face recognition:
  • Use clear, well-lit photos of students' faces
  • Ensure the face is clearly visible with no obstructions
  • Multiple face images per student improve recognition accuracy
  • Retrain the model after adding new students or updating face data
